# Messenger Project

Современный фулстек-мессенджер с упором на скорость работы, устойчивость к отвалам сети и удобный интерфейс. Проект построен на архитектуре монорепозитория (Turborepo), что позволяет держать клиентскую и серверную части в одном месте и управлять ими без боли.

## 🔥 Что под капотом

Это не просто очередная мертвая чатилка, а отказоустойчивая платформа. Главные фичи:

*   **Real-time на максималках:** Мгновенная доставка сообщений и статусов через Socket.io. Фоновое авто-переподключение и тихое обновление протухших сессий. Пользователя никогда не выкинет на экран логина из-за истекшего токена.
*   **Продвинутая работа с медиа:** Поддержка отправки видео и изображений (с функцией зума) через интеграцию с Cloudinary.
*   **Групповые чаты и модерация:** Создание групп, назначение админов, гибкое управление участниками и возможность добавлять людей прямо из контактов.
*   **Умные уведомления:** Индикация прочтения, бейджи непрочитанных сообщений и браузерные пуши, даже если вкладка свернута.
*   **Статусы присутствия:** Мониторинг онлайна юзеров в реальном времени.

## 🛠 Стек технологий

*   **Frontend:** Next.js 14, Tailwind CSS (Mobile First адаптивность), Zustand.
*   **Backend:** Node.js, Express, Socket.io.
*   **База данных:** PostgreSQL + Prisma ORM.
*   **Инфраструктура:** Turborepo.

## 🚀 Как запустить эту машину локально

### 1. Подготовка
Убедитесь, что у вас стоит Node.js (версия 20+) и запущен локальный PostgreSQL (или есть ссылка на облачную БД).

### 2. Установка
Клонируем репозиторий и ставим зависимости из корня проекта:
```bash
npm install
```

### 3. Переменные окружения
Создайте файлы `.env` в соответствующих папках приложений.

**apps/server/.env:**
```env
DATABASE_URL="postgresql://user:password@localhost:5432/messenger"
JWT_ACCESS_SECRET="твой_секрет_для_доступа"
JWT_REFRESH_SECRET="твой_секрет_для_рефреша"
# Настройки для Cloudinary
CLOUDINARY_URL=cloudinary://api_key:api_secret@cloud_name
```

**apps/web/.env.local:**
```env
NEXT_PUBLIC_API_URL="http://localhost:8080/api"
NEXT_PUBLIC_SOCKET_URL="http://localhost:8080"
```

### 4. База данных
Синхронизируем схему Prisma с вашей базой данных:
```bash
npm run db:push
npm run db:generate
```

### 5. Запуск
Заводим сразу и фронт, и бэк одной командой из корня:
```bash
npm run dev
```
Фронтенд будет ждать вас на `http://localhost:3000`.

## 🚢 Деплой в продакшен (Railway / Vercel)

Чтобы всё завелось на сервере без проблем, учтите пару критичных моментов:

1.  **Скрипты сервера:** В `apps/server/package.json` команда билда должна обновлять клиент Prisma перед компиляцией TypeScript, иначе билд упадет:
    `"build": "prisma generate && tsc"`
2.  **Фронтенд:** Не забудьте прописать `NEXT_PUBLIC_API_URL` и `NEXT_PUBLIC_SOCKET_URL` в настройках переменных окружения на хостинге.
3.  **Миграции:** Для автообновления базы при деплое можно использовать `prisma db push --accept-data-loss` в стартовом скрипте бэкенда. Для серьезного продакшена — `npx prisma migrate deploy`.

## 📁 Структура монорепы

*   `apps/web`: Фронтенд (Next.js). Весь визуал, стейт-менеджмент и логика интерфейса.
*   `apps/server`: Бэкенд (Express). API, сокет-сервер и логика взаимодействия с БД.
*   `packages/shared`: Общая логика, типы данных и утилиты.

## 📖 Базовое руководство пользователя

### 1. Вход и регистрация
При первом запуске создайте аккаунт. Достаточно указать почту, имя пользователя и пароль. Мессенджер запомнит вас, и при следующем входе вводить данные не придется (благодаря Refresh Tokens).

### 2. Как найти собеседника
Чтобы начать чат, сначала нужно добавить человека в контакты:
*   Перейдите в раздел **Contacts** (иконка человечка слева).
*   Нажмите **Add Contact** и введите имя пользователя или почту друга.
*   Как только он появится в списке, нажмите на него, чтобы открыть чат.

### 3. Групповые чаты
Если вам нужно обсудить что-то компанией:
*   В списке чатов нажмите иконку **«+»** или кнопку создания группы.
*   Введите название группы.
*   Внутри группы админы могут нажать на заголовок чата, чтобы открыть панель управления и добавить новых участников из своего списка контактов.

### 4. Личный профиль
Вы можете изменить свой аватар и описание:
*   Нажмите на свой аватар в левом нижнем углу.
*   Загрузите новое фото. Оно сразу обновится у всех ваших собеседников.

### 5. Уведомления
Для лучшего опыта разрешите браузеру отправлять уведомления от сайта. Так вы не пропустите важное сообщение, даже если работаете в другом окне.
